ครั้งแรกที่เปิด

BoomBigNose เก็บข้อมูลบนเครื่องคุณ ไม่ได้ส่งบัญชีหรือฐานข้อมูลขึ้นคลาวด์ หน้านี้เป็นคำอธิบายของตัวติดตั้งที่เผยแพร่แล้ว ยังไม่ได้คลิกทดสอบบนเครื่องจริง

โฟลเดอร์ข้อมูล

  1. ถ้าไม่ได้ตั้ง BOOMBIGNOSE_DATA ข้อมูลอยู่ที่ ~/.local/share/boombignose/pg
  2. บน Windows โฟลเดอร์นั้นคือ %USERPROFILE%\.local\share\boombignose\pg
  3. เส้นทางที่มีช่องว่างใช้ไม่ได้ โปรแกรมจะไม่สร้างคลัสเตอร์ในโฟลเดอร์แบบนั้น
  4. เปิดครั้งแรกจะสร้างคลัสเตอร์เมื่อยังไม่มีไฟล์ PG_VERSION

อัปเกรดจาก v0.3

ตัวติดตั้ง boombignose-v0.3.0, boombignose-v0.3.1, boombignose-v1.0.0, boombignose-v1.1.0 และ boombignose-v1.2.0 ใช้โฟลเดอร์เดียวกัน ถ้ามี PG_VERSION อยู่แล้ว โปรแกรมจะไม่รัน initdb ซ้ำ บัญชีและข้อมูลที่สร้างไว้จึงยังอยู่ในโฟลเดอร์นั้น

ถอนการติดตั้งแล้วติดตั้งรุ่นถัดไปในโฟลเดอร์โปรแกรมใหม่ ก็ยังอ่านโฟลเดอร์ข้อมูลเดิม อย่าลบโฟลเดอร์นั้นถ้าต้องการเก็บข้อมูล

บันทึกของ Postgres

เมื่อโปรแกรมเป็นฝ่ายสตาร์ท Postgres บันทึกถูกเขียนที่ server.log ในโฟลเดอร์ข้อมูล เช่น ~/.local/share/boombignose/pg/server.log

ตัวติดตั้ง boombignose-v1.0.0 ถ้า 127.0.0.1:54329 มีโปรแกรมฟังอยู่แล้ว จะไม่สตาร์ท Postgres ซ้ำ และจะใช้ตัวที่ฟังอยู่ บันทึกของตัวนั้นอาจไม่ใช่ server.log ของโฟลเดอร์นี้

ตั้งแต่ boombignose-v1.1.0 โปรแกรมไม่ใช้ตัวที่ฟังอยู่ถ้า postmaster.pid ไม่ใช่ของโฟลเดอร์ข้อมูลนี้ หน้าต่างค้างที่ข้อความที่ขึ้นต้นด้วย เปิด ERP ไม่สำเร็จ และบอก server.log กับ BOOMBIGNOSE_PG_PORT ถ้า postmaster.pid ตรงกับโฟลเดอร์นี้ โปรแกรมใช้คลัสเตอร์เดิม รวมข้อมูลที่ v0.3 สร้างไว้ ถ้า 127.0.0.1:3100 รับการเชื่อมต่อแล้ว แต่ GET /api/health ไม่ได้คืน {"ok":true} โปรแกรมจะไม่เปิดทับพอร์ตนั้น

พอร์ตบนเครื่องนี้

ERP อยู่ที่ 127.0.0.1:3100 Postgres อยู่ที่ 127.0.0.1:54329 พร็อกซี Auth อยู่ที่ 127.0.0.1:54321 Ollama ถ้าเปิดใช้ จะอยู่ที่ 127.0.0.1:11434 ไม่มีพอร์ตเหล่านี้เปิดออกอินเทอร์เน็ตจากตัวโปรแกรม

ถอนการติดตั้ง

บน Windows รัน %LOCALAPPDATA%\BoomBigNose\uninstall.exe สคริปต์ลบโปรแกรมและโฟลเดอร์ bundle ไม่ได้ลบโฟลเดอร์ข้อมูล

บน macOS ให้ลบโฟลเดอร์ที่คัดลอกจากแผ่น หรือลบ BoomBigNose.app บน Linux ให้ลบโฟลเดอร์ที่แตกจาก tar.gz หรือลบไฟล์ AppImage โฟลเดอร์ข้อมูลและไฟล์โมเดลที่ Ollama เก็บไว้ยังอยู่

หน้า AI

การเปิดโปรแกรมไม่ได้ดึงโมเดล ถ้าต้องการให้หน้า AI ตอบ ให้กดปุ่มดาวน์โหลด qwen3:4b บนสแปลช หรือรัน boombignose pull-model คำขอแชทไปที่ 127.0.0.1:11434 เท่านั้น โฮสต์คลาวด์ถูกปฏิเสธก่อนส่งคำขอ
