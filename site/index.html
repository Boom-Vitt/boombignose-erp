Roadmap

ใช้ภายในก่อน แล้วต่อยอดเป็นสินค้า open-core

ทุกตารางมี org_id และขอบเขตโมดูลชัดเจนตั้งแต่วันแรก จึงขยายเป็น Community + Pro ได้โดยไม่ต้องเขียนใหม่

V1 — MVP ภายใน ✓ เสร็จแล้ว

  • Auth + บทบาท owner/admin/member
  • แดชบอร์ด, CRM, โปรเจกต์, การเงิน
  • คลังเทมเพลต + webhook n8n
  • ข้อมูลเดโม SME ไทยจำลอง

V2 — คมขึ้น ✓ เสร็จแล้ว

  • โครงเชื่อม FlowAccount / PEAK / Xero
  • รายงาน, export, saved views
  • ผู้ช่วย AI + ติดตามอัตโนมัติ
  • Audit log + auth พร้อมใช้จริง

V3 — ทำเป็นสินค้า กำลังจะมา

  • Multi-org จริง (org switcher, คำเชิญ)
  • Self-host + deploy คำสั่งเดียว
  • Community Edition (AGPL)
  • Pro: SaaS, SSO, RBAC, white-label
ตั้งใจไม่ทำ: สต็อก, จัดซื้อ, เงินเดือน และการออกใบกำกับภาษี — บัญชีตามกฎหมายยังอยู่กับ FlowAccount / PEAK / Xero ระบบนี้คือ ชั้นปฏิบัติการ ไม่ใช่สมุดบัญชีหลัก
