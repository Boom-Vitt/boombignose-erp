BoomBigNose
สำหรับธุรกิจไทย

หน้าต่างเดสก์ท็อปสำหรับ BoomBigNose ERP ข้อมูลและกติกาอยู่ที่ 127.0.0.1 บนเครื่องที่คุณเปิดโปรแกรม Local desktop harness. No cloud model calls at runtime. macOS and Windows builds come first. Linux is later.

ดาวน์โหลด

macOS และ Windows มาก่อน Linux เป็นแพลตฟอร์มรอง ไฟล์ทั้งสามเป็นตัวติดตั้งคำสั่งฮาร์เนส ไม่ใช่หน้าต่าง ERP

macOSarm64 ดิสก์อิมเมจไม่ได้ลงชื่อด้วยใบรับรองร้านค้า ใช้ขั้นตอน Open Anyway BoomBigNose-macos-arm64.dmg Windowsx64 ตัวติดตั้งไม่ได้ลงชื่อ ใช้ More info แล้ว Run anyway BoomBigNose-windows-x64-setup.exe
Linux amd64
แพลตฟอร์มรอง ไฟล์เป็นคำสั่งฮาร์เนสชุดเดียวกับปุ่มด้านบน BoomBigNose-linux-amd64.tar.gz

ไฟล์บนแท็ก boombignose-v0.1.1 เป็นคำสั่ง boombignose check และ boombignose cutover ค่าแฮชอยู่ที่ SHA256SUMS หน้านี้เป็นเว็บนิ่ง ไม่ได้เปิด ERP และไม่ได้เรียกโมเดล

เมื่อมีไฟล์แล้ว ระบบปฏิบัติการจะเตือน

ไฟล์ชุดแรกไม่ได้ใช้ใบรับรองจากร้านค้าแอป การเตือนเป็นของระบบ ไม่ใช่ความผิดพลาดของตัวติดตั้ง

macOS

  1. เปิดไฟล์ .dmg แล้วลากแอปไปที่โฟลเดอร์ Applications
  2. ถ้า macOS บอกว่าเปิดไม่ได้ ให้คลิกขวาที่แอป แล้วเลือก Open
  3. หรือไปที่ System Settings แล้วเข้า Privacy & Security แล้วกด Open Anyway
  4. อ่านข้อความบนจอก่อนกดเปิด เครื่องจะไม่ข้ามคำเตือนให้เอง

Windows

  1. เปิดตัวติดตั้ง .exe
  2. ถ้า SmartScreen ขึ้น ให้กด More info แล้วกด Run anyway
  3. Smart App Control อาจบล็อกแอปที่ไม่ได้ลงชื่อ การตั้งค่าอยู่ที่ Windows Security แล้วเลือก App & browser control
  4. ถ้า Smart App Control บล็อกไว้ การกด Run anyway อาจไม่พอ ต้องตรวจการตั้งค่าบนเครื่องนั้น

จุดเด่น

ตัวเดสก์ท็อปห่อ ERP ที่มีอยู่แล้ว งานขาย โปรเจกต์ การเงินบนเอกสาร แดชบอร์ด และงานอัตโนมัติในเครื่อง

ลูกค้าและดีล

รายชื่อลูกค้าและขั้นของดีลอยู่ในโปรแกรมบนเครื่องคุณ

โปรเจกต์

งานและเวลาที่บันทึกไว้ใช้ฐานข้อมูลเดียวกับลูกค้า

การเงินบนเอกสาร

ใบเสนอราคา ใบแจ้งหนี้ และยอดเป็นสตางค์จำนวนเต็ม หน้านี้ไม่ได้บอกว่าเป็นสมุดบัญชีตามกฎหมาย

แดชบอร์ด

ตัวเลขสรุปจากข้อมูลในเครื่อง ไม่ได้ส่งตารางไปให้บริการแชทบนอินเทอร์เน็ต

งานอัตโนมัติในเครื่อง

ตัวตรวจของฮาร์เนสปฏิเสธคีย์ของบริการโมเดลและที่อยู่ที่ไม่ใช่ 127.0.0.1

ซอร์สเปิดให้อ่าน

โค้ดอยู่ที่ GitHub ข้อความสัญญาอนุญาตอยู่ในรีโป ไม่ได้สรุปซ้ำบนหน้านี้

วิธีใช้

1. ดาวน์โหลดไฟล์ของระบบคุณ

macOS arm64 และ Windows x64 มาก่อน ชื่อไฟล์อยู่บนปุ่มดาวน์โหลด

2. ติดตั้งแล้วยอมรับคำเตือนของระบบ

ใช้ขั้นตอน Open Anyway หรือ More info แล้ว Run anyway ตามระบบที่คุณเปิด

3. โปรแกรมเปิด ERP ที่เครื่องนี้

เป้าหมายคือหน้าต่างที่โหลด http://127.0.0.1:3100 พอร์ตนี้ใช้ได้ทีละโปรแกรม

คำถามที่พบบ่อย

กดดาวน์โหลดแล้วได้อะไร?

ได้ไฟล์ตัวติดตั้งคำสั่งฮาร์เนสบนแท็ก boombignose-v0.1.1 ไม่ใช่หน้าต่าง ERP

ทำไมระบบถึงเตือนตอนเปิดไฟล์?

เพราะชุดแรกไม่ได้ลงชื่อด้วยใบรับรองของร้านค้าแอป ขั้นตอนด้านบนคือทางที่ระบบให้กดต่อ

Linux มีไฟล์ไหม?

มีไฟล์ tar.gz สำหรับ amd64 เป็นแพลตฟอร์มรอง เนื้อในเป็นคำสั่งฮาร์เนสชุดเดียวกับ macOS และ Windows

ข้อมูลลูกค้าไปไหน?

เป้าหมายของผลิตภัณฑ์คือฐานข้อมูลบนเครื่องที่เปิดโปรแกรม ไม่ใช้โมเดลบนอินเทอร์เน็ตตอนทำงาน

หน้าเว็บนี้คือตัวโปรแกรมหรือ?

ไม่ใช่ GitHub Pages โชว์หน้านี้เท่านั้น ERP เปิดจากโปรแกรมบนเครื่อง
