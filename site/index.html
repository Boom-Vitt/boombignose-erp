สามขั้น

1. เลือกไฟล์ของระบบ

เวอร์ชัน boombignose-v0.2.0 มี macOS arm64, Windows x64 และ Linux amd64

2. ยอมรับคำเตือนของระบบ

ไฟล์ไม่ได้ลงชื่อร้านค้า ใช้ Open Anyway หรือ More info แล้ว Run anyway

3. เปิดบนเครื่อง

หน้าต่างปฏิเสธคีย์คลาวด์ แล้วเปิด http://127.0.0.1:3100 ถ้าพอร์ตว่างและพบซอร์สในเครื่อง มันจะสั่ง serve ให้ ไฟล์นี้ไม่ได้รวม Docker, Postgres หรือ Ollama และยังไม่ถูกคลิกทดสอบบนเครื่องจริง

เปิดไฟล์ที่ไม่ได้ลงชื่อ

macOS

  1. เปิดไฟล์ .dmg
  2. ถ้าเปิดไม่ได้ ให้คลิกขวาที่ไฟล์แล้วเลือก Open
  3. หรือไปที่ Privacy & Security แล้วกด Open Anyway
  4. เครื่องจะไม่ข้ามคำเตือนให้เอง

Windows

  1. เปิดไฟล์ .exe
  2. ถ้า SmartScreen ขึ้น ให้กด More info แล้ว Run anyway
  3. Smart App Control อาจบล็อกแอปที่ไม่ได้ลงชื่อ
  4. การกด Run anyway อาจไม่พอ ต้องตรวจการตั้งค่าบนเครื่องนั้น

Linux

  1. แตกไฟล์ .tar.gz แล้วได้โปรแกรมชื่อ BoomBigNose หรือใช้ไฟล์ AppImage
  2. ต้องมี WebKitGTK 4.1 ในระบบ
  3. แพลตฟอร์มนี้เป็นลำดับรองของชุดเดียวกัน

ความเป็นส่วนตัว

ผลิตภัณฑ์ตั้งใจไม่เรียกโมเดลบนอินเทอร์เน็ตตอนทำงาน และไม่ส่งตารางลูกค้าออกไป หน้าเว็บนี้เป็นไฟล์นิ่ง ไม่มีตัววัดผู้ชม ฟอนต์โหลดจาก Google Fonts เพื่อตัวอักษรไทยและละติน การโหลดฟอนต์นั้นเป็นการขอไฟล์จากภายนอกเฉพาะหน้านี้

คำถามและความต้องการของเครื่อง

ต้องมีอะไรบนเครื่อง

Windows x64, macOS arm64 หรือ Linux amd64 พร้อม WebKitGTK 4.1 ไฟล์ v0.2.0 ไม่ได้รวม Docker, Postgres หรือ Ollama ไว้ในตัว

หน้านี้คือโปรแกรมหรือ

ไม่ใช่ GitHub Pages แสดงหน้านี้ หน้าต่างเปิด ERP ที่ 127.0.0.1:3100 ชุดนี้คอมไพล์ใน CI และยังไม่ถูกคลิกทดสอบบนเครื่องจริง
