วิธีติดตั้ง

ตัวติดตั้งไม่ได้ลงชื่อด้วยใบรับรองที่ซื้อมา ระบบจึงถามก่อนเปิด ขั้นตอนนี้ยังไม่ถูกคลิกทดสอบบนเครื่องจริง

Windows เครื่องนี้

  1. เปิด BoomBigNose-windows-x64-setup.exe
  2. ถ้า SmartScreen ขึ้น ให้กด More info แล้วกด Run anyway
  3. Smart App Control อาจยังบล็อกแอปที่ไม่ได้ลงชื่อ การกด Run anyway ไม่ได้รับรองว่าจะผ่านนโยบายนั้น
  4. ตัวติดตั้งเป็น NSIS ระดับผู้ใช้ โฟลเดอร์เริ่มต้นคือ %LOCALAPPDATA%\BoomBigNose ไม่ได้ขอสิทธิ์ผู้ดูแลระบบ
  5. เปิด BoomBigNose จากเมนู Start หน้าต่างจะสตาร์ท ERP ที่ 127.0.0.1:3100

macOS เครื่องนี้

  1. เปิดไฟล์ .dmg มีเฉพาะ Apple silicon (arm64) ไม่มีไฟล์สำหรับ Intel
  2. คัดลอก BoomBigNose และโฟลเดอร์ bundle ออกจากแผ่นไปยังโฟลเดอร์ที่เขียนได้ แผ่นแบบอ่านอย่างเดียวอาจทำให้สิทธิ์รันหายไป จากนั้นรัน chmod +x BoomBigNose
  3. ถ้าแผ่นมี BoomBigNose.app ให้เปิดแอปนั้นได้ แอปลงชื่อแบบ ad-hoc ไม่ใช่ใบรับรองนักพัฒนาที่ซื้อจาก Apple
  4. ถ้า Gatekeeper ปฏิเสธ ให้คลิกขวาที่ไฟล์แล้วเลือก Open หรือไปที่ System Settings > Privacy & Security แล้วกด Open Anyway
  5. เครื่องจะไม่ข้ามคำเตือนให้เอง

Linux เครื่องนี้

  1. แตก tar.gz แล้วได้โปรแกรมชื่อ BoomBigNose กับโฟลเดอร์ bundle จากนั้นรัน chmod +x BoomBigNose
  2. หรือใช้ AppImage: chmod +x ไฟล์ BoomBigNose-linux-amd64.AppImage แล้วเปิด ถ้าเครื่องไม่มี FUSE ไฟล์นี้อาจเปิดไม่ได้
  3. ต้องมี WebKitGTK 4.1 ในระบบ บน Debian หรือ Ubuntu แพ็กเกจที่พบบ่อยคือ libwebkit2gtk-4.1-0
  4. เปิดแล้วเป็นหน้าต่าง ไม่ใช่คำสั่ง harness

เครื่องที่รองรับ

ระบบปฏิบัติการ

  • Windows x64 ตัวติดตั้งไม่ได้ลงทะเบียนใน Apps & features เพราะสคริปต์ไม่ได้เขียนรายการถอนการติดตั้งของระบบ
  • macOS arm64 เท่านั้น
  • Linux amd64 พร้อม WebKitGTK 4.1

พื้นที่และเครือข่าย

ไฟล์ตัวติดตั้งใหญ่หลายร้อยเมกะไบต์ตามจำนวนไบต์ในการ์ดด้านบน ฐานข้อมูลและโมเดลอยู่คนละที่กับตัวติดตั้ง แชทไม่เรียกโมเดลบนคลาวด์ การกดดึงโมเดลจะติดต่อคลังของ Ollama

สิ่งที่อยู่ในไฟล์

รุ่น boombignose-v0.3.0 รวมของเหล่านี้ไว้ในตัวติดตั้ง ไม่มี Docker

BoomBigNose

โปรแกรมที่เปิดชื่อ BoomBigNose และเป็นหน้าต่างที่ 127.0.0.1:3100 ไฟล์พก Node 22 กับ server.js ไว้ข้างใน เพื่อไม่ต้องลง Node แยก Node เป็นรันไทม์ในไฟล์ ไม่ใช่ชื่อแอป

Postgres

Postgres 16.10.0 แบบพกพา ฟังที่ 127.0.0.1:54329 ผู้ใช้ boombignose แบบ trust โฟลเดอร์ข้อมูลที่มีช่องว่างจะถูกปฏิเสธ

Auth

Auth v2.197.0 และ PostgREST v16.5 พร็อกซีที่ 127.0.0.1:54321 ส่ง /auth/v1 ไปพอร์ต 54323 และ /rest/v1 ไปพอร์ต 54324

Ollama

Ollama v0.40.11 ไม่รวมน้ำหนักโมเดล Linux กับ Windows ไม่รวมตัวรัน cuda_v12 และ cuda_v13 ปุ่มบนหน้าสแปลชหรือคำสั่ง boombignose pull-model เท่านั้นที่จะดึง qwen3:4b การเปิดโปรแกรมไม่ได้ดึงโมเดล

ครั้งแรกที่เปิด

  1. เปิด BoomBigNose หลังติดตั้ง โปรแกรมสร้างคลัสเตอร์ถ้ายังไม่มี
  2. ข้อมูลอยู่ที่ BOOMBIGNOSE_DATA หรือ ~/.local/share/boombignose/pg บน Windows คือ %USERPROFILE%\.local\share\boombignose\pg เส้นทางที่มีช่องว่างใช้ไม่ได้
  3. เบราว์เซอร์ในหน้าต่างเปิด ERP ที่ http://127.0.0.1:3100 สมัครและเข้าสู่ระบบบนเครื่องนี้
  4. ถ้าต้องการหน้า AI ให้กดปุ่ม “ดาวน์โหลดโมเดล qwen3:4b” บนสแปลช หรือรัน boombignose pull-model คำสั่งนี้ติดต่อคลังโมเดลของ Ollama แชทยังส่งไปที่ 127.0.0.1:11434
  5. การสตาร์ทใน CI เป็นคำสั่ง health, สมัคร, และเข้าสู่ระบบ ไม่ใช่การคลิกบนเครื่องจริง และไม่ได้ดึงโมเดล

ถอนการติดตั้ง

Windows

รัน %LOCALAPPDATA%\BoomBigNose\uninstall.exe สคริปต์ลบโปรแกรม โฟลเดอร์ bundle และทางลัดในเมนู Start ไม่ได้ลบโฟลเดอร์ข้อมูล และไม่ได้ลงรายการใน Apps & features

macOS

ลบโฟลเดอร์ที่คัดลอกออกจากแผ่น หรือ BoomBigNose.app แล้วดีดแผ่นออก โฟลเดอร์ข้อมูลยังอยู่จนกว่าจะลบเอง

Linux

ลบโฟลเดอร์ที่แตกจาก tar.gz หรือลบไฟล์ AppImage โฟลเดอร์ข้อมูลและน้ำหนักโมเดลที่ Ollama เก็บไว้ไม่ถูกลบตามไปด้วย

เมื่อเปิดไม่ได้

SmartScreen หรือ Gatekeeper

Windows ใช้ More info แล้ว Run anyway macOS ใช้ Open Anyway ใน System Settings > Privacy & Security Smart App Control อาจบล็อกต่อไป ไม่มีใบรับรองที่ซื้อมาให้ข้ามขั้นตอนนี้

สิทธิ์รันบน macOS หรือ Linux

หลังคัดลอกจากแผ่นหรือหลังดาวน์โหลด ให้ chmod +x โปรแกรมหรือ AppImage ก่อนเปิด

พอร์ตถูกใช้แล้ว

โปรแกรมใช้ 3100, 54321, 54323, 54324, 54329 และ 11434 บน 127.0.0.1 ถ้าพอร์ตใดถูกจับอยู่ การสตาร์ทจะไม่ผ่าน

แชทไม่มีคำตอบ

Ollama ต้องทำงานอยู่และต้องมีการดึง qwen3:4b แล้ว การเปิดโปรแกรมไม่ได้ดึงให้ โฮสต์อื่นที่ไม่ใช่ loopback ถูกปฏิเสธ

คำถาม

มีใน App Store หรือไม่

ไม่มี หน้านี้ให้ดาวน์โหลดไฟล์ตรงเท่านั้น ไม่ได้ส่งแอปเข้า Apple App Store, Google Play หรือ Microsoft Store

ไฟล์ลงชื่อแล้วหรือ

ไม่มีใบรับรองที่ซื้อจาก Apple หรือ Authenticode macOS ที่เป็น .app ลงชื่อแบบ ad-hoc เท่านั้น ตัวติดตั้งรุ่นที่เผยแพร่จึงยังขึ้นคำเตือนของระบบ

ทดสอบคลิกบนเครื่องจริงแล้วหรือ

ยังไม่ทดสอบ การตรวจใน CI บูตชุดที่อยู่ในตัวติดตั้งแล้วเรียก health, สมัคร, และเข้าสู่ระบบ ไม่ได้คลิก SmartScreen หรือ Open Anyway
